
Komenda import-inpost-dp-from-dpm-csv
=====================================

Import INPOST

Dodano nową komendę:

```bash
manage.py import-inpost-dp-from-dpm-csv
```

Komenda importuje z pliku CSV informacje o punktach impost.
Plik może znajdować się w `data/media/delivery_point/inpost.csv` w root volkanos.
CSV powinna być w formacie wygenerowanym przez aplikację DPM (delivery point manager).
